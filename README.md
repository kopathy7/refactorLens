## 🚀 Overview

RefactorLens is a static analysis platform that helps developers understand dependency relationships, visualize software architecture, and estimate the impact of code changes before refactoring.

Instead of relying on manual searches across hundreds of files, RefactorLens analyzes a codebase to answer questions like:

- What breaks if I delete this function?
- Which modules depend on this file?
- How are components connected?
- What is the impact of this change?
